# 🛒 E-Ticaret Web Sitesi

HTML ve CSS kullanılarak hazırlanmış, öğrenci seviyesinde bir e-ticaret sitesi arayüzü projesidir. JavaScript kullanılmamıştır.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![Font Awesome](https://img.shields.io/badge/Font%20Awesome-528DD7?style=flat&logo=fontawesome&logoColor=white)

---

## 📌 Proje Hakkında

Bu proje, web geliştirme dersi kapsamında hazırlanmıştır. Amaç; HTML ile sayfa yapısını, CSS ile de tasarımı oluşturmayı öğrenmektir.

## ✨ Özellikler

- 🔝 Üst menü (navbar) ve logo
- 🔍 Arama çubuğu
- 📂 Fare ile üzerine gelince açılan **Kategoriler** menüsü
- 🛍️ Ürün kartları (ikon, ürün adı, fiyat ve "İncele" butonu)
- ✨ Kartların üzerine gelince yukarı kalkma efekti
- 🔐 Giriş Yap ve Kayıt Ol sayfaları
- 📞 İletişim bilgileri (footer)
- 📱 Mobil uyumlu (responsive) tasarım

## 📁 Dosya Yapısı

```
e-commerce-project/
│
├── Eticaret.html    → Ana sayfa
├── Eticaret.css     → Tüm sayfaların tasarım dosyası
├── giris.html       → Giriş sayfası
├── kayit.html       → Kayıt sayfası
└── README.md        → Proje açıklaması
```

## 🚀 Nasıl Çalıştırılır?

1. Projeyi bilgisayarına indir veya klonla:
   ```
   git clone https://github.com/canpolatinan/e-commerce-project.git
   ```
2. Klasörü aç.
3. `Eticaret.html` dosyasına çift tıkla. Site tarayıcıda açılır.

> 💡 İkonların görünmesi için internet bağlantısı gerekir (Font Awesome internetten yüklenir).

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Ne için kullanıldı? |
|---|---|
| HTML5 | Sayfa yapısı |
| CSS3 | Renkler, yerleşim, açılır menü, mobil uyum |
| Font Awesome 6 | İkonlar |
